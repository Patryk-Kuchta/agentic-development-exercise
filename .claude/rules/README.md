# Rules

Rules load into **every** conversation, so they are pure context cost. Keep them
short — only what is needed on every single turn.

Everything else belongs in a skill, which loads on demand. If it is a procedure,
a lookup table, or a list of gotchas, it is a skill, not a rule.

One file: `project.md` — the stack, the derivation chain, the two project rules,
the gate command. Resist adding a second.
