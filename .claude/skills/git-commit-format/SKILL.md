---
name: git-commit-format
description: Format git commit messages to this repo's conventions. Use when writing a commit message, amending one, or reviewing commit history for consistency.
---

- Single line. No body.
- Imperative mood: "Add retry to fetch", not "Added" or "Adds".
- Max 72 characters.
- No `Co-Authored-By` trailers.

Good: `Add record-permission-request hook`
Bad: `fixed stuff.`
